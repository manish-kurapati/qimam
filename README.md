## QMAM (Qimam Al-Intaj Contracting Co. | شركة قمم الإنتاج للمقاولات)
Premium Corporate & Infrastructure Contracting Web Platform.

### Features
- **12 Specialized Capabilities**: Including phased execution workflows (Main Steps) and HSE safety protocols (Safety Measures) for each service.
- **378+ Unit Heavy Equipment Fleet**: Full specifications, category filters, and operational metrics.
- **Project Portfolio**: Mega civil infrastructure, earthworks, highways, and Vision 2030 developments.
- **Work in Action**: Cinematic field operations gallery, high-definition lightbox, and interactive video showcase.
- **Bilingual Support**: Instant toggle between English and Arabic (`عربي`).
- **Responsive System**: Mobile-optimized 2-by-2 card layout with zero horizontal clipping.

### Development & Build
```bash
# Build static routes to dist/
node build.mjs

# Start local server
node server.mjs
```
